# Phase 4 — MATDA BIZ 상세

## 1. 포지셔닝
MATDA BIZ는 기업이 외주/전문업체를 찾는 공간이다.

초기 핵심:
`업체 구함 → 비교견적`

장기:
`RFQ → 계약관리 → 민간입찰`

## 2. 소비자 영역과 관계
- 동일 사용자/인증 기반
- 동일 채팅 코어
- 동일 요청/견적 코어 최대 재사용
- URL은 초기 `/biz`
- BIZ가 커지면 서브도메인 검토 가능

## 3. BIZ 홈
모바일:
- MATDA BIZ
- 지역/검색
- 4~6개 주력카테고리
- 기업 요청 피드
- 내 사업장(Phase 5)

PC:
- 기업 검색
- 카테고리
- 최근 기업요청/RFQ
- 우측 내 사업장/마감

## 4. B2B 카테고리 전체 풀
초기 노출은 4~6개만.

1. 산업안전·보건
2. 전기·에너지
3. 소방·방재
4. 시설·건물관리
5. 환경·폐기물
6. 검사·인증·품질
7. IT·기업운영
8. 경영지원·전문대행

향후 Fleet/차량관리 등 추가 가능.

## 5. 구체 예시
### 산업안전·보건
안전관리대행, 보건관리대행, 위험성평가, 교육, 작업환경측정

### 전기·에너지
전기안전관리대행, 전기점검, 충전시설관리, 에너지관리

### 소방·방재
소방안전관리, 점검, 유지보수

### 시설
시설관리, 냉난방, 기계설비, 승강기, 청소, 경비, 주차

### 환경
폐기물, 대기/수질, 방역, 환경측정

### 검사·품질
비파괴검사(NDT), 품질검사, ISO, 시험/인증, 계측기교정

### IT
IT유지보수, 네트워크, CCTV, 보안, ERP, 웹

### 경영지원
세무, 회계, 노무, 법무, 특허, 채용/교육, 지원사업

## 6. 기업 요청
기본필수:
- 내용
- 지역
- 카테고리

선택/추천:
- 회사 업종
- 사업장 규모
- 계약전력
- 근로자수
- 희망 시작일
- 계약기간
- 첨부파일

모든 B2B 카테고리에 동일한 필드를 강제하지 않는다.

## 7. 업체 자격
법정업무는 업체가 해당 자격/등록을 갖춰야 한다.
플랫폼이 해당 업무를 직접 수행하는 것으로 표현하지 않는다.

예: 비파괴
- 비파괴검사업 등록 확인
- UT/MT/PT/RT 등 가능범위
- 관련 허가/기술인력 문서

검증은 관리자 프로세스로 기록한다.
