# Phase 2 — 민간 견적 상세

## 1. 원칙
별도 견적앱을 만드는 것이 아니라 기존 `[구해요]` 글이 업그레이드된다.

기존:
`[구해요] 입주청소 업체 구합니다 · 댓글 7`

이후:
`[구해요] 입주청소 업체 구합니다 · 견적 3/5 · 댓글 7`

## 2. 견적 활성화
구해요 작성 시:
- `업체 견적 받기` ON/OFF

기존 글에서도 작성자가 견적을 켤 수 있게 할 수 있다.

## 3. 요청 기본정책
설정값:
- `quote_default_limit = 5`
- `quote_max_limit = 10`
- `quote_default_hours = 72`
- `extension_hours = 24`
- `max_extensions = 2`
- `active_request_limit = 5`
- `same_category_active_limit = 2`

5개 견적 도달 시 1차 마감.
고객이 `견적 더 받기`로 추가 5개 활성화.

## 4. 고객 요청 추가정보
모두 선택형을 기본으로 한다.
- 희망일
- 예산
- 사진
- 평수/수량 등 카테고리 보조값

카테고리별 질문은 2~4개 이하.

## 5. 업체 견적
### 필수
- 금액
- 한줄설명

### 선택
- 가능일
- 예상시간
- 포함범위
- 추가비용 조건
- 견적서 첨부

## 6. 업체 견적 템플릿
업체가 자주 쓰는 견적을 저장.
예:
`입주청소 기본`
- 기본설명
- 포함범위
- 예상시간
- 추가비용문구

견적 작성 시 불러온 뒤 금액만 수정할 수 있게 한다.

## 7. 카테고리 예시
### 청소
- 작업인원
- 예상시간
- 포함범위

### 이사
- 차량
- 인원
- 포장
- 사다리차

### 자동차
- 부품비
- 공임
- 부품브랜드
- 작업시간

세부템플릿은 확장형 metadata로 설계.

## 8. 비교 UI
모바일:
- 카드형
- 선택한 2~3개 비교

PC:
- 카드 또는 비교표

공통 비교:
- 가격
- 가능일
- 핵심조건
- 업체 평점/후기
- 인증상태

## 9. 연락처
기본:
- 선택 전 비공개
- 내부채팅 가능
- 고객이 업체 선택
- 옵션으로 업체 수락
- 연락처 unlock

정책은 config로 변경 가능.

## 10. 거래완료
`selected`는 `completed`가 아니다.

고객 확인과 업체 완료확인을 별도 저장.
후기 작성 조건도 설정 가능.

## 11. 초기 무료
업체 견적 횟수를 지나치게 제한하지 않는다.
무료 공급자를 최대한 모은다.

## 12. 통과기준
- 5개 제한
- 72시간 만료
- 연장
- 추가 5개
- 견적 제출/수정
- 비교
- 채팅
- 선택
- 연락정책
- 거래확인
- 후기
모두 정상.
