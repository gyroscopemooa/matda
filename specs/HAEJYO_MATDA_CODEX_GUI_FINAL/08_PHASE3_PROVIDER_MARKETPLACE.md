# Phase 3 — 업체 마켓/프로필/MY

## 1. 업체 프로필
- 업체명
- 로고/대표이미지
- 한줄소개
- 상세소개
- 활동지역
- 서비스 카테고리
- 포트폴리오
- 후기
- 사업자 확인 상태
- 전문 자격/등록 상태
- 응답 관련 내부지표

## 2. 업체 검색
초기 필터:
- 지역
- 서비스
- 업체명

필터를 과도하게 늘리지 않는다.

## 3. 업체 카드
- 업체명
- 대표서비스
- 지역
- 평점/후기
- 인증 badge
- 대표이미지
- `채팅` / `견적 요청`

## 4. 업체 MY
- 새로운 요청 탐색
- 보낸 견적
- 고객이 선택한 견적
- 채팅
- 프로필 관리
- 포트폴리오
- 저장 견적 템플릿
- 활동통계

## 5. 통계
업체 본인에게:
- 견적 보낸 수
- 고객이 확인한 수
- 채팅 전환
- 선택된 수
- 후기 수

공개 프로필에 낮은 성사율을 무분별하게 노출하지 않는다.

## 6. 검증 상태
`unverified / pending / verified / rejected / expired`

문구는 신중하게:
- `사업자 확인`
- `등록증 확인`

실제 정부 인증이 아닌데 `정부 인증업체`처럼 표시하지 않는다.
