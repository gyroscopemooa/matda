# Phase 1 — Community MVP 상세

## 1. 목적
견적 플랫폼이라는 학습 없이 **그냥 커뮤니티 글을 올려 사람/업체와 연결**되게 한다.

## 2. 초기 글 타입
필수:
- `request` 구해요
- `question` 질문
- `review` 후기

선택 feature flag:
- `info` 정보
- `provider_post` 업체글

업체홍보는 스팸 가능성이 있으므로 초기에는 빈도 제한/관리자 제어 가능하게 한다.

## 3. 초기 소비자 카테고리 6개
1. 청소
2. 이사·운송
3. 수리·설치
4. 인테리어·시공
5. 자동차
6. 기타

세부카테고리를 작성 필수로 만들지 않는다.

## 4. 모바일 홈
- 지역
- 검색
- `전체 / 구해요 / 질문 / 후기`
- 최신 피드
- floating 또는 하단 중앙 글쓰기

카드:
- 타입 badge
- 제목
- 짧은 본문
- 지역/카테고리
- 사진여부
- 댓글수
- 작성시간

## 5. 글쓰기
필수:
- 타입
- 내용(제목은 자동/선택 가능)
- 지역
- 카테고리

선택:
- 사진
- 상세 지역

초기 글쓰기는 한 화면 또는 매우 짧은 sheet/dialog로 끝나야 한다.

## 6. 사진
일반글 기본 5장.
업로드 전 client-side resize/compress.
권장 긴 변 1600~2000px, 파일당 300KB~1MB 목표.

## 7. 댓글
- 작성/삭제
- 대댓글은 MVP에서 선택
- 신고
- 업체/인증 뱃지 표시 가능

## 8. 채팅
최소:
- 1:1
- 게시글에서 시작 가능
- 읽지않음 수
- 텍스트
- 이미지/파일은 이후 추가 가능

## 9. MY
고객 초기:
- 내가 쓴 글
- 댓글/관심(선택)
- 채팅
- 계정/지역

업체 역할을 추가하면 업체 메뉴가 자동으로 붙는다.

## 10. 검색
초기:
- 제목/본문
- 지역
- 카테고리
- 타입

복잡한 필터 금지.

## 11. 신고/차단
최소한:
- 글 신고
- 댓글 신고
- 사용자 차단
- 관리자 숨김/삭제

## 12. Phase 1 통과 기준
`가입 → 글쓰기 → 사진 → 피드 → 상세 → 댓글 → 채팅 → MY`가 모바일/PC에서 모두 정상.

활성사용자 수가 적어도 Phase 2 개발로 이동한다.
