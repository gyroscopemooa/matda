# 검색 / SEO / 지역

## 1. 지역
초기 글쓰기:
- 시/도
- 시/군/구

동 단위 선택.
정확한 주소를 모든 사용자에게 요구하지 않는다.

GPS 자동위치는 초기 필수 아님.
사용자가 직접 지역을 고르는 구조로 시작.

## 2. 검색 단계
### Community
글 제목/본문/카테고리/지역.

### Quote
서비스 카테고리/요청 검색.

### Provider
`글 / 업체` 탭 추가 가능.

### BIZ
기업 서비스/업체/RFQ/입찰 분리.

## 3. SEO URL
초기 한 도메인 권장.

- `/`
- `/community`
- `/posts/[id]`
- `/services/[slug]`
- `/providers/[slug-or-id]`
- `/biz`
- `/biz/services/[slug]`
- `/biz/rfqs/[id]`
- `/biz/tenders/[id]`

## 4. SEO 원칙
지역명만 바꾼 얇은 페이지 대량생성 금지.
실제 업체/요청/정보가 있는 페이지에만 고유 콘텐츠 제공.

## 5. 브랜드 분리
경로 기반으로 시작:
- root consumer
- `/biz` MATDA BIZ

BIZ가 독립 사업규모가 되면 서브도메인 검토.
처음부터 SEO 권위를 분산하지 않는다.

## 6. 메타
서비스/지역/업체 페이지마다 고유 title/description.
Structured data는 실제 데이터가 충분할 때 추가.
