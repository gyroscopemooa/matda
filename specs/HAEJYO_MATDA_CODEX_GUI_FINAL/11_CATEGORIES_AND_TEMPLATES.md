# 카테고리 및 템플릿 전체 목록

## A. 초기 Community 6개
1. 청소
2. 이사·운송
3. 수리·설치
4. 인테리어·시공
5. 자동차
6. 기타

## B. 민간견적 확장 카테고리
필요 데이터가 쌓이면 `기타`에서 승격.

1. 청소·생활관리
2. 이사·운송
3. 수리·설치
4. 인테리어·시공
5. 자동차
6. 생활·행사
7. 프리랜서 서비스
8. 기타

심리/상담 전문플랫폼은 별도 브랜드 전략이므로 이곳에 깊게 통합하지 않는다.

2. 전기·에너지

# 템플릿 1 — 일반글
- 타입
- 제목(선택/자동 가능)
- 내용
- 지역
- 카테고리
- 사진

# 템플릿 2 — 소비자 구해요
기본필수:
- 내용
- 지역
- 카테고리

선택:
- 사진
- 희망일
- 예산
- 추가정보

# 템플릿 3 — 업체 견적
필수:
- 금액
- 한줄 설명

선택:
- 가능일
- 예상시간
- 포함범위
- 추가비용
- PDF/XLSX 견적서

# 템플릿 4 — 업체 저장견적
- template name
- category
- default message
- default scope
- default duration
- extra cost note

# 템플릿 5 — 업체 프로필
- 업체명
- 소개
- 지역
- 서비스
- 포트폴리오
- 사업자/등록정보
- 후기

# 템플릿 6 — 기업 구해요
- 내용
- 사업장 지역
- 카테고리
- 희망 시작일
- 첨부
- 카테고리 보조정보

# 템플릿 7 — B2B RFQ
- 제목
- 업무범위
- 마감
- 수행기간
- 참가조건
- 첨부
- 가격/조건 제출필드

# 템플릿 8 — Tender
- 공고명
- 발주기업
- 업무범위
- 참가조건
- 시작/마감
- 선정방식
- 첨부
- 투찰가격
- 제안서

# 템플릿 9 — 계약
- 회사/사업장
- 서비스
