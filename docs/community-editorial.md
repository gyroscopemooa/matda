# 커뮤니티 수동 운영

## 게시와 수정

기존 `/community` 목록과 `/posts/{id}` 상세를 사용한다. 새 게시판이나 URL은 만들지 않는다. 운영자도 본인 계정으로 글을 작성하며 타인의 본문을 대신 수정할 권한은 추가하지 않는다. 관리자 숨김·복원 권한은 기존대로 유지한다.

1. 운영자 Google 계정으로 로그인하고 MY → 운영 관리 → **커뮤니티 글 직접 작성**을 선택한다. 일반 커뮤니티 글쓰기에서도 같은 기능을 이용한다.
2. 안내 글은 질문 유형과 정확한 분야를 선택한다. 자유 글도 가능하지만 분야가 없으면 자동 관련 글 추천은 하지 않는다. 운영자 관계를 본문에 밝힌다.
3. 제목, 본문을 직접 작성하고 필요하면 사진을 첨부한다(기존 최대 5장). 사진에 개인 정보와 권리 문제가 없는지 확인한다.
4. `그냥 등록`은 즉시 공개 게시다. 이번 변경에는 임시저장·예약발행을 추가하지 않는다.
5. 상세 화면의 **수정**, 또는 MY의 내 글에서 수정한다. 기존 글 URL은 유지된다.
6. 설명형 내부 링크는 `[입주청소 사진 준비 방법](/posts/실제글ID)` 또는 `[청소 요청 준비 안내](/guides/cleaning-request)`처럼 입력한다. HTML과 임의 스크립트는 해석하지 않는다. 주소가 실제로 존재하고 공개 중인지 운영자가 확인한다.

## “지금 커뮤 글 작성해줘” 요청 처리 기준

- 실제 검색 실적이 있으면 노출이 많고 클릭이 적은 검색어를 검토한다. 없으면 확인 가능한 반복 질문·사용자 문의·실제 문제를 근거로 선정한다. 검색량·순위·인기도를 꾸미지 않는다. 같은 질문을 다룬 기존 글이 있으면 먼저 개선한다.
- 글 하나는 질문 하나를 해결한다. **구체적인 제목 → 첫 문단 핵심 답 → 준비 조건과 실행 순서 → 안 되는 경우와 대안 → 관련 안내 → 실행 가능한 서비스 링크** 순서로 작성한다.
- 확인한 기능만 설명한다. 가짜 사용 후기, 반복 문구, 키워드 나열을 금지한다. Phase 1에서는 커뮤니티 글쓰기·댓글·채팅과 공개 가이드만 안내하며 견적 모집·제출·선택이나 결제 가능성을 약속하지 않는다.
- 새 글과 관련 기존 글을 양방향으로 연결하고 목적을 설명하는 링크 문구를 사용한다. 기존 글 본문을 실제 수정했는지, 상세의 추천 영역만 달라졌는지 구분해 보고한다.
- 외부 커뮤니티용 글은 본문만으로 해결 방법이 전달되게 작성한다. 운영자 관계를 밝히고 게시판 규칙을 따른다. 외부 게시 자체는 이 구축 요청의 범위가 아니다.
- 조회수 외에 질문 해결 반응, 링크 클릭, 서비스 이용을 검토해 기존 글을 개선한다. 실제 측정 자료가 없으면 수치를 추정하지 않는다. 검색 실적 자동 연동은 하지 않으며, 제공받은 CSV로 분석을 시작할 수 있다. 이번 구현은 새 클릭·전환 추적기를 추가하지 않는다.
- 작성 결과에 **제목·본문 / 해결 질문 1개 / 연결할 기존 글과 링크 위치 / 추가 사실 확인이 필요한 부분**을 포함한다. 대량 글을 임의 생성하지 않는다.

## 이번 구현 범위와 제한

- 공개 커뮤니티 목록·본문을 익명 데이터로 서버에서 렌더링한다. 검색 허용 환경에서 공개 일반 글과 커뮤니티 목록을 색인 허용하고 사이트맵에 넣는다. 샘플·숨김·기업 비공개 영역은 제외한다. 실제 검색 색인·노출은 검색엔진이 결정한다.
- 관련 글은 같은 분야이고 확인 가능한 주제 단어가 겹치는 경우만 후보로 삼는다. 서로의 최근 3개 후보에 포함된 글만 연결해 양방향과 최대 3개 제한을 지킨다. 오래된 글은 관련 최근 글이 있어도 이 제한 때문에 추천이 없을 수 있다. 관련성이 없으면 억지로 추천하지 않는다. 필요한 연결은 운영자가 본문에 수동 추가한다.
- 관련 가이드와 가이드의 관련 커뮤니티 글도 분야·주제를 확인한다. 추천은 각 화면의 최근 데이터로 계산되며 기존 본문을 재작성하거나 저장하지 않는다. 수동 본문 링크의 양방향 수정은 별도 편집 작업이다.
- 새 AI API, 예약·자동발행, 검색 실적 연동, 운영 SQL 변경은 없다. 저장소에 있던 가이드 생성·자동화 기능은 이번 작업과 별개이며 호출하거나 설정을 변경하지 않는다.
- 커밋·push·배포는 별도 승인 대상이다. 이전 Google 태그 수정의 push 승인은 이 기능의 배포 승인이 아니다.
