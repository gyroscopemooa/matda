# 민간 견적 플랫폼 전환 계획

결정일: 2026-09-20
상태: 향후 Phase용 계획. 이번에는 문서만 저장하며 현재 UI·권한·기능을 활성화하지 않는다.

## 역할 변화
Phase 1은 요청형 커뮤니티가 중심이다. 현재 글종류 해줘요/질문/후기/자유를 유지한다. 참고안의 구해요는 현재 명칭 해줘요를 뜻하며, 업체글을 새 글종류로 지금 추가하지 않는다.
Phase 2는 견적 요청/비교/선택이 중심이다. 해줘요는 정식 견적 요청으로 통합하고 질문/후기/경험공유는 보조 커뮤니티에 유지한다. 가이드는 운영팀 정보 콘텐츠로 분리한다.
Phase 3에서 업체찾기와 업체 프로필을 활성화하며 업체 소개·홍보는 해당 영역으로 이동한다. Phase 4에서 기업서비스를 노출한다. 최종 헤더를 Phase 2부터 한꺼번에 노출하지 않는다.

## 요청 전환과 데이터 보존
- 해줘요 글을 별도로 다시 작성시키지 않는다. 작성자가 전환을 선택하면 기존 내용을 가져와 작업 범위 등 필요한 조건만 보완한다.
- 기존 글 URL·내용·사진·댓글·채팅 연결을 보존하고 견적 요청과 연결한다. 기존 글을 자동으로 공개 견적 모집 상태로 전환하지 않는다.
- 견적 수/마감은 실제 상태를 표시한다. 예시의 3/5·D-2는 디자인 예시이며 실제 건수로 사용하지 않는다.
- 기존 일반 후기는 유지하되 실제 거래 연결 후기와 구분한다. 확인되지 않은 후기에 거래 인증을 붙이지 않는다.
- 자유 글은 이용량과 운영 부담을 보고 경험공유로 정리하거나 메뉴를 축소한다. 임의 삭제하지 않는다.

## 화면 방향
견적 단계 홈: 서비스 검색 → 요청 작성 → 최근 요청/받은 견적 → 해당 Phase에 공개된 업체/후기 영역.
최종 PC 헤더 후보: 홈 / 견적받기 / 업체찾기 / 커뮤니티 / 해죠 가이드 / 기업서비스.
모바일 주요 메뉴: 홈 / 요청하기 / 채팅 / MY. 홈 안에 질문·후기 및 가이드 진입점을 둔다.
커뮤니티와 가이드에서 관련 요청 작성으로 연결하되 같은 일을 두 번 등록하지 않게 한다.

## 다음 단계 완료 조건
전환 동의/중복 방지, 기존 링크 보존, 로컬·전국 온라인 요청, 접근 권한, 실제 견적 집계와 마감, 거래 연결 후기 구분을 검증한다. 검색유입·신뢰 상승은 목표이며 보장된 효과로 표현하지 않는다.
