## 이번 작업

- 기존 해줘요 글 상세에서 `견적 요청으로 전환` → `동의하고 시작`. 새 글을 복사하지 않고 원래 ID를 유지한다.
- 기존 요청의 일반 수정으로 견적 ON/OFF를 바꾸거나 분야를 바꾸는 우회를 차단한다.
- 오래된 글의 모집기간은 전환 시점부터 계산한다. `quoteStartedAt`이 없는 과거 로컬 견적은 기존 생성일 기준을 유지한다.
- SQL `0015_quote_request_conversion.sql`: 작성자 행 잠금으로 한도 확인과 전환을 직렬화, 게시글별 unique 요청, 72시간/최대120시간/5→10개, 요청 시작 동의, 활성 계정·공개 글·샘플 제외 검사.
- 원격 집계는 금액/본문을 반환하지 않는 RPC로 가져오며, 다른 업체의 견적이 RLS에 숨겨져도 실제 총 개수를 유지한다.
- Phase 1에서는 새 RPC를 조회하지 않는다. 기존 원격 서비스가 0015 없이 계속 작동한다.

## 검증

- 단위·PostgreSQL/RLS 시뮬레이션 및 원격 어댑터 mock 테스트 41개 통과. 타입검사·린트·Phase 2 프로덕션 빌드 통과.
- 실제 Phase 2 로컬 서버에서 Edge PC 1440px/모바일 390px: 동의 오류, 전환, 동일 URL/댓글 유지, 새로고침 지속, 가로 넘침 검사 통과.
- 실제 Supabase에서 실행한 검증은 아니다. 테스트의 DB 잠금 로직 검사는 단일 PGlite 인스턴스 기준이며 다중 연결 부하 검증은 2F에 포함한다.

## 공개 상태와 다음 작업

2026-09-20 사용자 지시: 이번 변경은 로컬 커밋만 허용한다. 원격 push·배포·운영 SQL 적용·견적 공개는 진행하지 않는다. 커뮤니티 활성화 상황과 업체 응답 가능성을 검토한 뒤 공개 여부를 별도로 결정한다. 개발 완료율을 공개 결정 근거로 대신하지 않는다.

운영은 Phase 1 유지. 원격 API의 Phase 1 제한을 해제하지 않았다.
0015는 파일만 준비했으며 원격 DB에 적용하지 않았다. `consumer_quotes_enabled` 기본값은 false로, SQL을 적용해도 요청 모집을 자동 공개하지 않는다.
원격 `post.create` 견적 동시 생성, 업체 제출·선택·거래 RPC는 아직 연결되지 않았다. 현재 시점에 운영 환경의 `NEXT_PUBLIC_RELEASE_PHASE`를 2로 변경하면 안 된다.

다음은 **2B 원격 업체 역할·견적 제출**. Phase 3 업체찾기를 공개하지 않고도 Phase 2에서 업체 역할과 템플릿을 사용할 수 있도록 권한 구분부터 수정한다.
