## 검증 근거

- `npm test`: 44개 통과. PGlite에서 실제 PostgreSQL SQL/RLS 실행, Supabase 어댑터와 DB를 연결한 테스트 전송 계층 포함.
- `npm run dev:test:phase2` + `npm run test:e2e:phase2`: 실제 Phase 2 PC1440/모바일390 거래 흐름2개 및 기존 글 전환2개 통과.
- 모바일 가로 넘침 없음, 선택 전 연락처 없음, 선택 후 연락처 표시, 선택 후 견적/첨부 수정 차단, 채팅·양측 확인·후기 확인.
- 타입검사·lint·Phase 2 Next 프로덕션 빌드 통과.
- 기존 자유글 작성·지역/온라인 요청 회귀 E2E 2개와 커뮤니티 PC/360px 화면 E2E 1개 통과. 360px 서비스 메뉴의 가로 넘침을 스크롤로 수정했다.
- 원격 DB 다중 연결 부하/실제 스토리지 업로드/OAuth 검증은 아니다. 이 항목은 staging 적용 시 수행한다.

## 구현 파일

- SQL0015: 기존 글 전환/모집 정책·공개 집계. 기본 공개 플래그 false.
- SQL0016: 업체 역할/프로필/템플릿, 요청·견적·선택·채팅·연락처·확인·후기 RPC. 민감 데이터 직접 쓰기는 계속 차단.
- SQL0017: private 견적서 버킷/메타데이터/RLS. 요청자와 견적 작성자만 다운로드, 링크60초.
- 원격 API 기본값은 Phase 1. Phase 2 원격은 별도 `CONSUMER_QUOTES_REMOTE_ENABLED=true`와 DB 공개 플래그가 필요하다. 기존 Phase 1은 새 SQL 없이 동작한다.

## 로컬과 운영

- 사용자 테스트: `npm run preview` → http://127.0.0.1:3107/quotes. 구현된 후속 기능을 로컬 데이터로 사용한다. 실제 결제는 비활성.
- 정확한 Phase 2 경계: `npm run dev:test:phase2` → http://127.0.0.1:3118. 테스트 데이터는 실행마다 새로 만든다.
- 운영 재현: `npm run preview:release` (기존3107 서버 중지 후). 운영 wrangler 설정은 Phase 1 그대로.
- 기존 운영 확인: matda.net 견적 준비 중, `/quotes/new`·`/biz/rfqs`404, `/api/app`200·Supabase 모드. 이번 변경의 push·배포·운영 SQL 적용은 하지 않는다.
- 공개 여부는 커뮤니티 활성화와 업체 응답 준비를 보고 사용자가 결정한다. 개발 완료가 공개 승인을 대신하지 않는다.
