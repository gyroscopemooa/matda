# 해죠 가이드 운영

현재 구현: /guides, /guides/[slug], 운영팀 작성 가이드 6개, 카테고리/검색, 복사/공유 링크, 로그인 후 요청 양식 이어쓰기.
콘텐츠 원본: src/lib/guides.ts. 공개 항목은 status=published만 사용한다. draft는 방문자 목록/상세에서 제외한다. 공개 파일에는 내부 메모나 개인정보를 넣지 않는다.

## 발행 원칙
운영팀 콘텐츠임을 표시한다. 실제 사용자 후기/거래/견적 수를 생성하지 않는다. 작업 범위를 정리하는 체크리스트와 바로 쓸 요청 양식을 포함한다. 가격, 지급 비율, 법률, 보험 등은 최신 1차 출처와 적용 조건을 확인하기 전 공개하지 않는다. 카테고리별 금액 하한이나 응답 시간 보장을 임의로 약속하지 않는다.

## 다음 구현 범위
AI API 모델/비용 한도 설정 → 비공개 초안 DB와 관리자 권한 → 출처·중복·표현 검토 → 승인 및 예약 발행. 현재 자동 생성/스케줄러/관리자 편집 UI는 없다. 초기 요청 작성 완료, 실제 댓글 응답, 첫 응답까지 시간, 채팅 연결을 계측할 계획이며 아직 KPI 대시보드는 없다. 제공자 모집과 외부 연락은 별도 운영 작업이다.

검색엔진 공개는 출시 점검 후 적용한다. 현재 noindex이며 검색 순위/유입 효과를 보장하지 않는다.

## 2026-09-20 콘텐츠 주제 확장
주력은 맡기기 전후 바로 활용하는 팁·노하우다. 서비스 분야(청소·관리 등)와 편집 주제(요청 준비·선정/비교·생활 관리·계약/분쟁)를 별도 축으로 계획한다. 아직 주제 필터 UI를 추가한 것은 아니다.

편집 비중의 초기 참고값: 실용 팁/선정·비교 60%, 생활·관리·계절 정보 30%, 계약·결제·분쟁 예방 10%. 할당량을 채우기 위해 검토하지 않은 글을 발행하지 않는다.
일상 글은 집·차·작업·디지털 생활과 연결되는 주제로 다양화한다. 서비스와 무관한 유행/연예 글을 검색량만 보고 양산하지 않는다. 모든 글에 견적 CTA를 강요하지 않고 질문하기/체크리스트/관련 글 등 목적에 맞는 다음 행동을 둔다.

### 후속 주제 후보 — 아직 발행하지 않음
- 이사 전에 정리할 물건 목록 만들기
- 청소를 맡기기 전 귀중품과 개인 물건 정리
- 계절별 집 관리 일정표 만들기
- 수리 요청 사진에서 개인정보 가리기
- 작업 전후 사진으로 변경사항 기록하기
- 홈페이지 개편 전 콘텐츠 정리하기
- 업체에 물어볼 질문을 짧고 정확하게 쓰기
- 추가 작업이 생겼을 때 확인할 내용
- 계약금·중도금·잔금 조건을 확인하는 질문
- 분쟁 발생 시 기록 정리와 공식 상담 창구 확인

### 계약·분쟁·법률 콘텐츠 검토
가끔 발행하되 최신 법령·공식 기관 자료를 확인하고 출처 URL, 적용 대상/조건, 확인 날짜를 기록한다. 한국소비자원·공정거래위원회·국가법령정보센터 등의 해당 주제 1차 자료를 확인한다. 지급 비율, 환불 가능 여부, 책임·권리를 모든 업종에 통용되는 정답으로 단정하지 않는다. 일반 정보와 개별 사안 판단을 구분하고 근거가 불명확하면 초안 상태로 둔다. AI는 가상의 판례·통계·분쟁 사례를 실제 사례로 만들지 않는다.

계획된 자동화는 다양한 주제를 순환해 초안을 만들되, 법률/금액 관련 글은 검토 없이 예약 발행하지 않는다. 실제 자동화는 아직 미구현이다.
