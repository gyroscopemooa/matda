# 해죠 가이드 운영

현재 구현: /guides, /guides/[slug], 운영팀 작성 가이드 6개, 카테고리/검색, 복사/공유 링크, 로그인 후 요청 양식 이어쓰기.
콘텐츠 원본: src/lib/guides.ts. 공개 항목은 status=published만 사용한다. draft는 방문자 목록/상세에서 제외한다. 공개 파일에는 내부 메모나 개인정보를 넣지 않는다.

## 발행 원칙
운영팀 콘텐츠임을 표시한다. 실제 사용자 후기/거래/견적 수를 생성하지 않는다. 작업 범위를 정리하는 체크리스트와 바로 쓸 요청 양식을 포함한다. 가격, 지급 비율, 법률, 보험 등은 최신 1차 출처와 적용 조건을 확인하기 전 공개하지 않는다. 카테고리별 금액 하한이나 응답 시간 보장을 임의로 약속하지 않는다.

## 다음 구현 범위
AI API 모델/비용 한도 설정 → 비공개 초안 DB와 관리자 권한 → 출처·중복·표현 검토 → 승인 및 예약 발행. 현재 자동 생성/스케줄러/관리자 편집 UI는 없다. 초기 요청 작성 완료, 실제 댓글 응답, 첫 응답까지 시간, 채팅 연결을 계측할 계획이며 아직 KPI 대시보드는 없다. 제공자 모집과 외부 연락은 별도 운영 작업이다.

검색엔진 공개는 출시 점검 후 적용한다. 현재 noindex이며 검색 순위/유입 효과를 보장하지 않는다.
