# 지역 데이터 및 동작

- 원천: 행정안전부 법정동 코드. 사용한 공개 가공본: https://github.com/swuhalee/korea-regions-with-coords (full-korea-regions.json).
- 제공자 설명 기준일: 2026년 2월. 다운로드: 2026-09-20. **실시간 최신 행정구역 API가 아닌 고정 스냅샷**이다. 이후 행정구역 개편은 다음 데이터 갱신에 반영해야 한다.
- 원본 보관: docs/regions-source.json. 앱에는 좌표/리를 제외한 시도·시군구·읍면동 이름만 src/lib/regions-data.json으로 추출. 17 시도, 255 중간 구역(세종 구 없음 포함), 5,067 읍면동.
- 제공자가 표시한 원천 이용조건: 행정안전부 공공데이터 / 공공누리 제1유형. 가공본의 좌표는 사용하지 않음.
- 야음동은 법정동 선택이다. 행정동(야음장생포동 등) 목록과 혼용하지 않는다.
- 성남시 분당구 같은 일반구는 시/군/구 선택에 함께 표시. 세종은 시군구 선택 없이 읍면동 선택 가능.
- 글쓰기: 시도/시군구 필수(세종 예외), 읍면동 선택. 잘못된 조합은 서버에서도 거절.
- 필터: 전체 지역, 시도 전체, 시군구 전체, 읍면동 단위 선택. 카테고리/글 종류/검색어와 AND 조건. 브라우저에 저장해 새로고침 후 유지.
- 기존 서울/경기 등 축약 이름은 정규화해 필터 비교. 기존 데이터의 불완전한 자유주소를 임의로 새 동에 배정하지 않는다. 편집할 때 정확한 지역을 다시 선택한다.
- 신규 가입은 지역 미설정. 글쓰기에서 선택한 필터 지역 또는 MY 기본 지역을 초깃값으로 사용. MY에서 기본 지역을 설정할 수 있다.
- 갱신 시 원천 기준일/변경내용을 기록하고 세종, 일반구, 동명이인 지역 및 과거 이름 호환 테스트를 실행한다.
